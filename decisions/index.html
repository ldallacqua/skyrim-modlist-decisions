Decisions

Accepted describes the list as it is. Proposed is a research-backed recommendation that hasn't been adopted yet. Records are never deleted, only superseded.

  1. 0001Pin the game at Skyrim SE 1.5.97 with Anniversary Edition contentThe list runs SkyrimSE.exe 1.5.97 with SKSE 2.0.20, loads AE Creation Club content, and uses BEES to read it.Accepted
  2. 0002Run from a separate game folder and test on a cloned profileMO2's game path points to a dedicated copy of the game, which Steam can't update.Accepted
  3. 0003Use function-based separators without numbersKeep the 17 separators named by function, leave them unnumbered, and fix only the two ends of the pane.Accepted
  4. 0004Build characters on CBBE 3BA, BodySlide and OBody NGThe body is CBBE 3BA with XPMSE, CBPC and Faster HDT-SMP for physics, built with BodySlide and distributed with OBody NG.Accepted
  5. 0005Generate behaviors with PandoraPandora Behaviour Engine+ 5.0.0-beta generates behaviors and writes them to its own output mod.Accepted
  6. 0006Render with Community ShadersCommunity Shaders 1.9.1 with its feature mods is the renderer, with no ENB.Accepted
  7. 0007Give each generator its own output mod at the end of the panePandora, BodySlide, AutoBlend, PGPatcher, SKSE, Root and shader cache output each live in their own mod under `Outputs`, and Overwrite stays empty.Accepted
  8. 0008Set each generator's output in the tool, not only in MO2Configure the output location the way each tool documents, because MO2's "create files in mod" only catches new files.Accepted
  9. 0009Place patches by what they connectA patch for one mod goes right below it, and a patch linking several sections goes in a late `Patches` section.Accepted
  10. 0010Sort with LOOT and record every exception as metadataLOOT sets the base order, and any exception is a `Load After` rule or a group, never a manual drag.Accepted
  11. 0011Clean plugins in batch, with backups, and judge warnings against our own mastersClean Load Order runs Quick Auto Clean on the active plugins, including official masters, and keeps the originals.Accepted
  12. 0012Keep the inbox separator last`Recently Added` sits below `Outputs` and must be empty at release.Accepted
  13. 0013Publish the real list, by whitelist, as text onlyThe repository holds the actual list, exported by a script that copies only named files and fields.Accepted
  14. 0014Extend grass with Grass Optimizations and NGIO, without a cacheNGIO draws grass out to 40000 units, Community Shaders' Grass Optimizations keeps that cheap, and there is no grass cache.Accepted
  15. 0015Keep TomatoRim's ground and Northern Roads at their own depths, and add road debrisThe ground stays TomatoRim PBR Landscapes, the roads stay Northern Roads with the converted Omen Apollo dirt, road and ground keep their texture sets' own depth values after two tuning attempts failed in game, and a small plugin adds debris to the dirt roads.Accepted

One person's list, not a guide to follow. Mods belong to their authors; no mod files are hosted here.
